# ⚡ PyStudio — Modern Python 3.12 Web IDE 🐍✨

> **Code anywhere, anytime — on PC or Mobile — with zero lag, zero server crashes, and VS Code-style speed!** 🚀💻📱

**PyStudio** is a sleek, responsive, browser-based **Python 3.12** compiler and editor designed for effortless coding on both desktop and mobile devices. Host it for free on **GitHub Pages** and start running Python scripts in seconds! 🌟

---

## 🔥 Why PyStudio?

* 🛡️ **Crash-Proof Under Heavy Traffic:** Runs **100% client-side** using **Pyodide (WebAssembly)** inside each visitor's own browser—so even if thousands of users visit at once, there is no central backend server to overload or crash! 🌐💪
* ⚙️ **Dedicated Web Worker Power:** Executes Python in a background worker thread so your editor stays smooth and responsive, plus lets you hit **■ Stop** anytime if an infinite loop happens! 🛑⚡
* 📁 **Full Multi-File Workspace:**
  * Create custom files with **`+ New File`** ➕
  * Rename existing files anytime with **`✎`** ✏️
  * Switch smoothly across tabs or remove files with **`×`** 🗑️
  * Import local `.py`, `.txt`, `.csv`, or `.json` files with **`↑ Import`** 📥
  * Import your custom `.py` modules seamlessly inside your code! 🔗
* 🧠 **VS Code-Inspired Smart Editing:**
  * **Auto-Closing Pairs:** Automatically closes `()`, `[]`, `{}`, `""`, and `''` on both mobile and desktop keyboards ✨⌨️
  * **Smart Autocomplete:** Type partial words and press `Enter` or `Tab` to complete quickly 💡
  * **Live Syntax Error Checker:** Spots syntax mistakes *before* you run your code, highlights the line, and lets you tap the error bar to jump straight to it! 🚨🎯
* 🖥️ **Instant Output & Interactive `input()`:** View outputs, errors, execution time (`ms`), and interactive `input()` prompts in a clean output view with **`← Editor`** and **`↻ Re-Run`** buttons! ⏱️💬
* 📱 **Built for Mobile & PC:** Includes a quick-tap symbol shortcut bar (`Tab`, `()`, `""`, `''`, `:`, `=`, `[]`, `{}`, `#`, `_`), one-tap **Copy** 📋, and **`.py` Download** 💾.

---

## ⌨️ Handy Shortcuts

* ▶️ **Run Code:** Tap **Run** or press `Ctrl + Enter` / `Cmd + Enter`
* ✨ **Autocomplete:** Start typing or press `Ctrl + Space`, then hit `Enter` or `Tab`
* 🎯 **Jump to Error:** Tap the red syntax bar below the editor to go right to the error line
